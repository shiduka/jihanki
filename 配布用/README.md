# 自動販売機管理アプリ（配布用パッケージ）

野菜の直売所などで使用するロッカー型自動販売機を管理するWebアプリケーションです。
商品の補充（在庫登録）、売れた商品の消込・売上計上、月別の売上分析を直感的なタップ操作で行えます。

## 特徴
- **複数台の自販機管理**: デフォルト2台（最大20台まで追加・名称変更可能）を切り替えて管理できます。
- **直感的な操作**: タップ操作中心の大きなボタン・金額別カラー表示で、誰でも迷わず使える設計です。
- **分析・売上管理**: 月ごとの商品別売上割合（円グラフ）や時間帯別売上推移（棒グラフ）、売上明細の確認・削除が可能です。
- **プライバシー・セキュリティ配慮**:
  - データはご自身の端末（ブラウザ）およびご自身が設定したGoogleスプレッドシートのみに保存され、外部の第三者サーバーへ送信されることはありません。
  - 管理画面の**暗証番号（PIN）ロック機能**や、クラウド同期時の**通信の合言葉（シークレットキー）機能**を搭載しています。
  - JSONバックアップ書き出し時には、クラウド接続URLや暗証番号などの機密情報が自動的に除外される安全設計です。

## 使い方

### ファイルを開く
`index.html` をブラウザ（Chrome, Edge, Safariなど）で開くか、GitHub Pages等のWebサーバーに配置して開いてください。

### 1. 販売者モード（商品の補充・管理）
1. 画面上部の **「販売者」** タブを選びます。
2. 商品を入れたい **「空き」** ロッカーをタップします。
3. **商品名** をプリセットボタンから選ぶか、直接入力します（1ロッカーに最大3商品まで登録可能）。
4. **価格** を選択し、必要に応じて「🎁 おまけを入れる」をONにします。
5. **「登録して施錠」** ボタンを押すとロッカーに商品が登録されます。
6. 登録済みのロッカーをタップすると、**「この商品をコピー」**（連続貼り付け）、**「管理者購入」**、**「取下げ（売上なし）」** が行えます。

### 2. 購入者モード（売れた商品のチェック・売上計上）
1. 画面上部の **「購入者」** タブを選びます。
2. 売れた商品のロッカーをタップして解錠（売上計上）します。
   - ※「管理」→「自販機設定」で **「ワンクリック購入モード」** をONにすると、1タップで即座に売上計上＆空ロッカーに戻せます（5秒間の「元に戻す」ボタン付き）。
   - ※ **「この自販機の商品を一括購入」** ボタンで、選択中の自販機の全商品をまとめて売上計上することも可能です。

### 3. 管理モード（分析・売上履歴・各種設定）
画面上部の **「管理」** タブを押すと管理メニューが開きます。

- **分析**: 表示月を指定して、商品別売上割合・時間帯別売上推移をグラフで確認できます。
- **売上管理**: 表示月ごとの売上履歴一覧と合計金額を確認・個別削除できます。
- **自販機設定**:
  - ワンクリック購入モードのON/OFF
  - クラウド同期（Googleスプレッドシート連携）の設定（※手順は `GAS_INSTRUCTIONS.md` を参照）
  - 自販機の台数追加・削除、および各自販機の名称設定（例：「店舗前」「駐車場」など）
- **プリセット**: よく使う商品名ボタンや金額ボタンを自由に追加・削除できます。
- **データ・保護**:
  - **管理画面の暗証番号（PIN）保護**: 4〜8桁の暗証番号で管理タブをロックできます。
  - **データのダウンロード / 取り込み**: JSONファイルとしてデータをバックアップ・復元できます。
  - **売上削除 / 全データ初期化**: 売上履歴のリセットや、端末内の全データを工場出荷状態に戻すことができます。
