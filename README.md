# 自動販売機管理アプリ

野菜の直売所などで使用するロッカー型自動販売機を管理するWebアプリケーションです。
100円硬貨を使用する物理的な自動販売機の操作をシミュレートし、売上管理を行うことができます。

## 特徴
- **2台管理**: 1号機と2号機を切り替えて管理できます。
- **直感的な操作**: タップ操作中心の大きなボタンで、キーボード入力が苦手な方でも使いやすい設計です。
- **データ管理**: ブラウザにデータを自動保存。JSONファイルとしてバックアップ・復元も可能です。

## 使い方

### ファイルを開く
`index.html` をブラウザ（Chrome, Edge, Safariなど）で開いてください。

### 1. 販売者の方へ（商品の補充）
1. 画面上部の**「販売者」**ボタンを押します。
2. 商品を入れたい**「空き」**ロッカー（グレー）をタップします。
3. **商品名**を選択または入力します。
   - よく使う野菜（トマト、きゅうり等）はボタン一発で入力できます。
4. **価格**を設定します（+100円、-100円ボタン）。
5. **「登録して施錠」**ボタンを押すと、ロッカーが緑色になり販売開始されます。

> **管理者機能**:
> - **硬貨不要購入**: 鍵の不具合などで手動で開ける際に、売上を計上しつつ解錠できます。
> - **取下げ**: 売れ残った商品を回収する際などに、売上を計上せずに解錠します。

### 2. 購入者の方へ（商品の購入）
1. 画面上部の**「購入者」**ボタンが選ばれていることを確認します（通常はこの状態）。
2. 欲しい商品が入っているロッカー（緑色）をタップします。
3. **「100円投入」**ボタンを押して、必要な金額を入れます。
4. 金額が足りると**「解錠して取り出す」**ボタンが押せるようになります。
5. ボタンを押すとロッカーが開き（グレーに戻り）、購入完了です。

### 3. 管理メニュー（設定・売上）
画面右上の **⚙️（歯車アイコン）** を押すと管理メニューが開きます。

- **売上管理**:
  - 日別・月別の売上を確認できます。
  - 間違った記録は「削除」ボタンで消すことができます。
- **プリセット設定**:
  - よく使う商品名のボタンを追加・削除できます。
- **データ管理**:
  - **データをダウンロード**: 現在の全てのデータ（ロッカー状態、売上、設定）をファイルに保存します。
  - **データを取り込み**: 保存したファイルを読み込んで、以前の状態に戻します。
